# 截图表格提取

把屏幕上的表格截图，交给 AI 识别成结构化数据，再一格一格粘贴到 Excel、表格或其他软件里。

适合：网页、软件、聊天记录里的表格不能直接复制，只能截图的情况。

---

## 一、下载与启动

- 直接双击 `截图表格提取.exe`，不需要安装 Python 或其他依赖。
- 第一次打开会自动弹出「设置」窗口。
- 程序保存的数据都在 `%APPDATA%\ScreenshotExtract` 下（设置、截图、运行日志 `log.txt`）。

---

## 二、第一次使用：配置接口

打开「设置」，先选「接口来源」。

### 方式 1：cgwimg 授权登录（默认，推荐）

1. 「接口来源」选 **cgwimg（授权登录，无需 Key）**。
2. 点 **授权登录**，浏览器会自动打开授权页面。
3. 在浏览器里登录 cgwimg，点 **同意授权**。
4. 回到程序，状态显示「授权成功，Key 已保存在本机」。
5. 点 **保存**。cgwimg 方式使用固定模型，不需要填写模型名称。

Key 只保存在你自己的电脑上。想换账号，点 **清除授权** 后重新授权。

### 方式 2：自定义 OpenAI 兼容接口

适用于你自己有 API Key 的情况。

1. 「接口来源」选 **自定义（OpenAI 兼容接口）**。
2. 填写 **Base URL**，例如 `https://api.openai.com/v1`。
3. 填写 **API Key**。
4. 填写 **模型名称**（仅自定义接口需要）。图片识别需要支持图片输入的模型，例如 `gpt-4o`；只做文本识别的话，任何对话模型都可以。
5. 点 **保存**。

### 其他设置

| 设置项 | 说明 |
|---|---|
| 截图快捷键 | 按下后截图，默认 `ctrl+shift+r` |
| 粘贴快捷键 | 粘贴模式下粘贴下一个单元格，默认 `ctrl+shift+v` |
| 提取格式（列名） | 用逗号分隔，例如 `项目,数量,单价`。留空则按截图表头自动识别 |
| 额外提取要求 | 例如「金额保留两位小数；忽略合计行」 |
| 图片 WebP 质量 | 发送前转换的图片质量，1–100，默认 85 |

**设置快捷键**：点一下快捷键输入框，然后直接按下想要的组合键，例如 `Ctrl+Shift+R`，不需要手动输入文字。按 `Esc` 可取消录制。组合键必须包含一个修饰键（Ctrl / Alt / Shift / Win）。如果提示「已被其他程序占用」，换一个组合即可。

## 三、基本流程

程序分两个标签页：

- **截图**：顶部是截图工具栏，左侧是截图列表，右侧是原图。
- **识别结果**：识别按钮和粘贴模式，左侧是结果表，右侧是详细。

### 1. 截图

1. 按 **截图快捷键**（或点工具栏的「截图」），截取当前范围（默认全屏）。
   - 已有的图片也可以加进来：点 **导入图片…** 可多选文件（png、jpg、bmp、webp、gif），或在资源管理器里复制图片后，直接按 Ctrl+V。
   - 导入的图片和截图一样，会参与识别。非图片文件会跳过，并在状态栏提示。
   - **文本识别**：点工具栏的 **文本识别…**，弹出输入框后，把微信聊天记录复制粘贴进去，点 **提取**。文本会作为一条记录加入截图列表（尺寸列显示「文本 N 字」），并立即识别。文本记录没有图片，右侧预览显示聊天原文。
2. 需要只截某个窗口时，点 **选择窗口…**，选中窗口后点「选择」。之后的截图都只截这个窗口，工具栏会显示窗口名。点窗口名右边的 **✕** 即可恢复为全屏。默认是全屏。
3. 截图出现在右侧的截图列表中，选中后右侧显示原图，**双击** 可放大查看。不需要的截图，在列表中 **右键 → 删除选中截图**。

截图顺序就是识别顺序，每张截图对应结果表里的若干行。

### 2. 识别

1. 点 **识别**，把所有未识别的截图发给 AI。
2. 截图按「每次请求张数」合并成一批发送。默认每次 3 张，可以在页面上调整（1–20）。合并发送可以减少请求次数，但每次图片更多，单次耗时会更长。
3. 识别完成后，结果出现在左侧表格中。
4. 结果表的每一行都记录了来源截图：
   - **点击任意一行**，「详细」显示这一行的完整内容；截图列表中会选中它的来源截图，右侧显示来源内容并高亮该行的位置：
     - 图片：在原图上用红框标出该行所在的位置。
     - 文本记录：在聊天原文中用黄色底色高亮该行对应的消息。
   - 同一张截图识别出的行使用相同底色。
   - 内容完全相同的行会标注 **⚠重复**，请人工确认是否需要保留。

#### 常用操作

| 操作 | 方法 |
|---|---|
| 删除一行 | 右键该行 → 删除此行 |
| 删除某张截图的全部结果 | 右键该行 → 删除此截图的全部结果行（截图保留） |
| 关闭某一列 | 点击表头列名，前面的 ☑ 变成 ☐，粘贴时整列跳过 |
| 重新识别 | 点 **重新识别全部**（会覆盖已有结果） |
| 清空识别结果 | 点 **清空识别结果**（截图保留） |
| 修改单元格 | 双击单元格直接修改，回车保存 |
| 设置粘贴起点 | 右键单元格 →「从这里开始粘贴」 |
| 清空截图 | 点工具栏的 **清空截图**（同时清空识别结果） |
| 导出表格 | 点 **导出表格…**，保存为 CSV 文件（所有列、所有行，顺序与界面一致） |

**导出表格**：生成的是 CSV 文件，编码为 UTF-8 带 BOM，用 Excel 直接双击打开中文不会乱码。导出的内容包括所有列，不受列开关影响；内容里有逗号或换行的单元格会自动加引号。

## 四、自动识别

勾选 **自动识别**，程序会自动处理待识别的截图：

- 待识别截图攒够「每次请求张数」时，**立即识别**这一批。
- 不足一批时，**每 60 秒**检查一次，把剩下的截图识别掉。

自动识别会处理「待识别」的截图。识别失败的截图会在失败后约 60 秒自动重试（接口持续出错时不会频繁重发）。手动点 **识别** 则立即重试。

未设置接口（或 cgwimg 未授权）时，自动识别会自动关闭。

## 五、粘贴模式：一格一格粘贴

这是本工具最省事的功能。

1. 切换到「识别结果」页，点 **粘贴模式：关**，变为 **粘贴模式：开**。
2. 打开你要填写的目标表格（例如 Excel），把光标放到第一个要填的单元格。
3. 按 **粘贴快捷键**（默认 `ctrl+shift+v`）。程序会把下一个未填的单元格内容放到剪贴板，并自动模拟 Ctrl+V 粘贴。
4. 每按一次，粘贴一格。已粘贴的格子会在结果表中标 ✓，下次自动跳过。
5. 目标表格里的光标要自己移动到下一格。程序只负责内容，不会移动你的光标。

**设置粘贴起点**：在结果表里右键某个单元格，选「从这里开始粘贴」，该格会标 ▶，之后按粘贴快捷键从它开始。不设置时，从第一格开始。

**手动修改结果**：双击任意单元格可直接修改内容，按回车保存。修改后的内容会按新值粘贴。

「识别结果」页右上角的 **进度 已完成/总数**：只统计开启的列，有内容的格子。

注意：

- 粘贴模式开启时，粘贴快捷键才生效。关闭后，按粘贴快捷键不会有任何动作。
- 按粘贴快捷键时，请确保焦点在目标软件里。
- 如果某列不需要粘贴，先把它的开关关掉（点表头），再开始粘贴。

## 六、常见问题

**Q：点「识别」没有反应，或一直显示「正在识别」**

- 看底部状态栏的提示。接口失败时会显示具体原因。
- 单次请求最多等待 120 秒，超时会显示错误。
- 详细错误记录在 `%APPDATA%\ScreenshotExtract\log.txt`。

**Q：提示 401 / 403 / 404 / 429**

| 状态码 | 常见原因 |
|---|---|
| 401 | Key 无效或过期。cgwimg 方式请重新授权；自定义方式检查 API Key。 |
| 403 | 没有该模型的权限、余额不足，或网关拦截。检查模型名称和权限。 |
| 404 | Base URL 或模型名称错误。 |
| 429 | 请求太频繁或额度用完。稍后再试，或把「每次请求张数」调小。 |

**Q：识别出来的行不完整、或某行归属的截图不对**

- 识别结果依赖模型输出。可以把截图裁剪得清晰一些，或在「额外提取要求」里说明表格结构。
- 行的归属依赖模型返回的图片序号，如有错位，可以用「删除此截图的全部结果行」后重新识别。

**Q：点结果行后，高亮的位置不对**

- 位置由模型估计，可能有偏差。文本记录的高亮依据模型给出的行号，一般比较准。
- 只有重新识别后的结果才有位置信息。旧的识别结果只显示原图或原文，没有高亮。

**Q：文本识别没有结果，或结果不完整**

- 确认粘贴的内容是完整的聊天记录，每条消息都在内容中。
- 文本识别和图片识别一样依赖模型输出。可以在「额外提取要求」中说明需要提取的字段，例如「只提取发送人和内容」。

**Q：快捷键没有生效**

- 状态栏会提示「无法注册（已被其他程序占用）」。在「设置」里换一个组合。
- 程序需要保持运行，快捷键才有效。

**Q：指定窗口截图失败，提示「窗口已最小化」**

- 最小化的窗口无法截取，请先把它还原，再截图。

**Q：截图内容不对（比如截到了别的窗口）**

- 指定窗口时，截图前程序会把该窗口置于最前。如果期间你切换了其他窗口，可能截到遮挡的内容，请保持目标窗口在前台再截图。

**Q：cgwimg 授权后看不到 Key**

- Key 只在本机保存，程序设置窗口里不显示完整 Key。授权成功后，直接保存设置即可使用。

## 七、开发者

入口是 `table_extractor.py`（界面），业务逻辑分在同目录的几个模块里：

| 文件 | 内容 |
|---|---|
| `table_extractor.py` | 界面：两个标签页、结果表、粘贴模式、设置窗口 |
| `app_config.py` | 路径、设置读写、日志、常量 |
| `recognize.py` | 图片转 WebP、接口调用、文本与图片的提示词、解析表格、后台识别线程 |
| `model.py` | 结果表的纯数据逻辑：重复行比对、删除行后的重新编号、CSV 导出 |
| `capture.py` | 全屏与窗口截图 |
| `hotkeys.py` | 全局快捷键、粘贴按键 |
| `cgw_auth.py` | cgwimg 授权登录 |

依赖：

```
pip install pillow
```

tkinter 随 Python 自带。仅支持 Windows（使用了全局快捷键和 Win32 截图接口）。

运行源码：

```
python table_extractor.py
```

打包成单文件 exe（输出到 `dist\截图表格提取.exe`）：

```
pyinstaller --noconfirm --onefile --windowed --exclude-module pkg_resources --name 截图表格提取 table_extractor.py
```

`--exclude-module pkg_resources` 是为了避免打包后启动时报 `jaraco.text` 相关错误。`build/`、`dist/` 和 `*.spec` 为构建产物，已在 `.gitignore` 中忽略。

结果行的位置信息（`_loc`）保存在每行数据中，不作为列，不会出现在导出的 CSV 中。
