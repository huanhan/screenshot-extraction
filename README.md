# 截图表格提取

把屏幕上的表格截图，交给 AI 识别成结构化数据，再一格一格粘贴到 Excel、表格或其他软件里。

适合：网页、软件、聊天记录里的表格不能直接复制，只能截图的情况。

---

## 一、下载与启动

- 直接双击 `截图表格提取.exe`，不需要安装 Python 或其他依赖。
- 第一次打开会自动弹出「设置」窗口。
- 程序保存的数据都在 `%APPDATA%\ScreenshotExtract` 下（设置、截图、运行日志 `log.txt`）。

---

## 二、第一次使用：配置接口

打开「设置」，先选「接口来源」。

### 方式 1：cgwimg 授权登录（默认，推荐）

1. 「接口来源」选 **cgwimg（授权登录，无需 Key）**。
2. 点 **授权登录**，浏览器会自动打开授权页面。
3. 在浏览器里登录 cgwimg，点 **同意授权**。
4. 回到程序，状态显示「授权成功，Key 已保存在本机」。
5. 「模型名称」填写要用的模型，例如 `gpt-6.1-sol`。
6. 点 **保存**。

Key 只保存在你自己的电脑上。想换账号，点 **清除授权** 后重新授权。

### 方式 2：自定义 OpenAI 兼容接口

适用于你自己有 API Key 的情况。

1. 「接口来源」选 **自定义（OpenAI 兼容接口）**。
2. 填写 **Base URL**，例如 `https://api.openai.com/v1`。
3. 填写 **API Key**。
4. 填写 **模型名称**，必须是支持图片输入的模型，例如 `gpt-4o`。
5. 点 **保存**。

### 其他设置

| 设置项 | 说明 |
|---|---|
| 截图快捷键 | 按下后截图，默认 `ctrl+shift+r` |
| 粘贴快捷键 | 复制模式下粘贴下一个单元格，默认 `ctrl+shift+v` |
| 提取格式（列名） | 用逗号分隔，例如 `项目,数量,单价`。留空则按截图表头自动识别 |
| 额外提取要求 | 例如「金额保留两位小数；忽略合计行」 |
| 图片 WebP 质量 | 发送前转换的图片质量，1–100，默认 85 |

快捷键格式示例：`ctrl+shift+r`、`ctrl+alt+s`、`f8`。必须包含一个修饰键（Ctrl / Alt / Shift / Win）。如果提示「已被其他程序占用」，换一个组合即可。

## 三、基本流程

整个过程分两个页面：

### 第 1 页：截图

1. 按 **截图快捷键**（或点「立即截图」），截取全屏。
2. 截图出现在左侧列表中，选中后右侧预览，**双击** 可放大查看。
3. 需要只截某个窗口时，点 **指定截图窗口…**，选中窗口后点「指定」。之后的截图都只截这个窗口。点 **恢复全屏** 可以改回全屏。
4. 不需要的截图选中后点 **删除选中**。

截图顺序就是识别顺序，每张截图对应结果表里的若干行。

### 第 2 页：识别结果

1. 点 **识别待处理**，把所有未识别的截图发给 AI。
2. 截图按「每次请求张数」合并成一批发送。默认每次 3 张，可以在页面上调整（1–20）。合并发送可以减少请求次数，但每次图片更多，单次耗时会更长。
3. 识别完成后，结果出现在表格中。
4. 结果表的每一行都记录了来源截图：
   - **点击任意一行**，右上方显示它对应的截图，下方「详细」显示这一行的完整内容。
   - 同一张截图识别出的行使用相同底色。
   - 内容完全相同的行会标注 **⚠重复**，请人工确认是否需要保留。

#### 常用操作

| 操作 | 方法 |
|---|---|
| 修改某个单元格 | 双击单元格，输入后按回车 |
| 删除一行 | 右键该行 → 删除此行 |
| 删除某张截图的全部结果 | 右键该行 → 删除此截图的全部结果行（截图保留） |
| 关闭某一列 | 点击表头列名，前面的 ☑ 变成 ☐，粘贴时整列跳过 |
| 重新识别 | 点 **重新识别全部**（会覆盖已有结果） |
| 清空结果 | 点 **清空结果**（截图保留） |
| 清空全部 | 在「截图」页点 **清空** |

## 四、自动识别

勾选 **自动识别**，程序会自动处理待识别的截图：

- 待识别截图攒够「每次请求张数」时，**立即识别**这一批。
- 不足一批时，**每 60 秒**检查一次，把剩下的截图识别掉。

自动识别只处理「待识别」的截图。识别失败的截图不会自动重试，避免反复消耗额度，需要你手动点 **识别待处理** 重试。

未设置接口（或 cgwimg 未授权）时，自动识别会自动关闭。

---

## 五、复制模式：一格一格粘贴

这是本工具最省事的功能。

1. 切换到「识别结果」页，点 **复制模式：关**，变为 **复制模式：开**。
2. 打开你要填写的目标表格（例如 Excel），把光标放到第一个要填的单元格。
3. 按 **粘贴快捷键**（默认 `ctrl+shift+v`）。程序会把下一个未填的单元格内容放到剪贴板，并自动模拟 Ctrl+V 粘贴。
4. 每按一次，粘贴一格。已粘贴的格子会在结果表中标 ✓，下次自动跳过。
5. 目标表格里的光标要自己移动到下一格。程序只负责内容，不会移动你的光标。

辅助按钮：

- **跳过下一个**：这一格不需要，跳过它。
- **重置进度**：清除所有 ✓ 标记，从头开始粘贴。
- 页面右上角的 **进度 已完成/总数**：只统计开启的列，有内容的格子。

注意：

- 复制模式开启时，粘贴快捷键才生效。关闭后，按粘贴快捷键不会有任何动作。
- 按粘贴快捷键时，请确保焦点在目标软件里。
- 如果某列不需要粘贴，先把它的开关关掉（点表头），再开始粘贴。

## 六、常见问题

**Q：点「识别待处理」没有反应，或一直显示「正在识别」**

- 看底部状态栏的提示。接口失败时会显示具体原因。
- 单次请求最多等待 120 秒，超时会显示错误。
- 详细错误记录在 `%APPDATA%\ScreenshotExtract\log.txt`。

**Q：提示 401 / 403 / 404 / 429**

| 状态码 | 常见原因 |
|---|---|
| 401 | Key 无效或过期。cgwimg 方式请重新授权；自定义方式检查 API Key。 |
| 403 | 没有该模型的权限、余额不足，或网关拦截。检查模型名称和权限。 |
| 404 | Base URL 或模型名称错误。 |
| 429 | 请求太频繁或额度用完。稍后再试，或把「每次请求张数」调小。 |

**Q：识别出来的行不完整、或某行归属的截图不对**

- 识别结果依赖模型输出。可以把截图裁剪得清晰一些，或在「额外提取要求」里说明表格结构。
- 行的归属依赖模型返回的图片序号，如有错位，可以用「删除此截图的全部结果行」后重新识别。

**Q：快捷键没有生效**

- 状态栏会提示「无法注册（已被其他程序占用）」。在「设置」里换一个组合。
- 程序需要保持运行，快捷键才有效。

**Q：指定窗口截图失败，提示「窗口已最小化」**

- 最小化的窗口无法截取，请先把它还原，再截图。

**Q：截图内容不对（比如截到了别的窗口）**

- 指定窗口时，截图前程序会把该窗口置于最前。如果期间你切换了其他窗口，可能截到遮挡的内容，请保持目标窗口在前台再截图。

**Q：cgwimg 授权后看不到 Key**

- Key 只在本机保存，程序设置窗口里不显示完整 Key。授权成功后，直接保存设置即可使用。

## 七、开发者

源码是单文件 `table_extractor.py`，依赖：

```
pip install pillow
```

tkinter 随 Python 自带。仅支持 Windows（使用了全局快捷键和 Win32 截图接口）。

打包成单文件 exe：

```
pyinstaller --noconfirm --onefile --windowed --exclude-module pkg_resources --name 截图表格提取 table_extractor.py
```

`--exclude-module pkg_resources` 是为了避免打包后启动时报 `jaraco.text` 相关错误。
